# 1 Laboratory Discussion

In this activity, I learned how to make changes appear on the screen when the user does something. One way works well for small changes that happen only on one page. Another way is more helpful when the same information is needed on several pages. I also learned that choosing the right method can keep the application organized. This activity helped me understand how different parts of the application can stay updated.

# 2 Laboratory Discussion

In this activity, I learned how the application gets product information from an online source. The information is arranged first before it is shown to the user. While the application is waiting, it can display a message so the user knows that the products are still loading. It can also show a message when something goes wrong. Separating the different tasks made the project easier for me to read, understand, and update.

# 3 Laboratory Discussion

In this activity, I learned how the application gets and displays shopping cart information. Each cart has its own details, so the application needs to know which cart the user wants to view. Once the correct information is found, it is shown on the details page. I also learned that separating each task makes the project less confusing. This activity helped me understand how information moves from its source to what the user sees on the screen.
